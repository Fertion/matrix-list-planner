# Matrix List Planner

An Obsidian.md plugin that provides a Bases view for drag-and-drop distribution of list-property items across files and an unassigned pool.

<img width="1546" height="357" alt="image" src="https://github.com/user-attachments/assets/f95c36e3-2a0f-4ae0-9119-4af790e60123" />


A custom **Obsidian Bases View** for visually distributing `list` property items using Drag & Drop.

### How it works

* **Rows** — files returned by the Bases query
* **Columns** — selected `list` properties
* **Cells** — list items
* **Unassigned** — a separate pool for items not yet assigned

Items can be freely moved between cells, rows, columns, and the **Unassigned** pool. Changes are automatically saved to the underlying properties.

### Usage

1. Create a Bases view and configure its filters.
2. Select the `list` properties you want to use as columns.
3. Switch the view to **Matrix List Planner**.
4. Drag and drop items to organize them.
